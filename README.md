# Scaler Neovarsity Landing Page

Static landing page for Scaler Neovarsity, structured after the OPGP page UI in black & white.

## Local development

```bash
python3 -m http.server 9876
# open http://localhost:9876
```

## Production (Railway)

```bash
npm start
# uses `serve` to host on $PORT
```

## Structure

Single-file `index.html` with Tailwind via CDN. Sections:

1. Hero
2. Video placeholder
3. Logo marquee
4. Why Neovarsity
5. Batch profile
6. Value pillars + featured card
7. Curriculum (core table + 3 specialisation buckets)
8. Cross-program electives
9. Instructors
10. Testimonials
11. Possible paths
12. Who it's for + eligibility
13. Placements
14. Degree & recognition
15. Why Scaler
16. Pricing / final CTA
17. FAQ
18. Awarded-by-Woolf banner
19. Footer
